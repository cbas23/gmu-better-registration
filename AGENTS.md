# AGENTS.md

## Project Overview

Browser extension (Chrome/Firefox) that enhances GMU course registration with RateMyProfessors data. Built with **WXT** + **SolidJS** + **TypeScript**.

## Commands

- `bun install` — install deps (postinstall runs `wxt prepare`, generates `.wxt/` + virtual modules)
- `bun run dev` — dev server (auto-reload)
- `bun run dev:firefox` — Firefox dev server
- `bun run build` — production build → `.output/chrome-mv3/`
- `bun run build:firefox` — Firefox production build
- `bun run compile` — type-check only (`tsc --noEmit`). **Must run `bun install` first** — `tsconfig.json` extends `.wxt/tsconfig.json` which is generated by `wxt prepare`
- `bun run zip` — package extension as .zip

No tests, no linter, no formatter configured.

## Architecture

WXT manages extension build, manifest, and entrypoint detection. Entrypoints auto-detected from `src/entrypoints/`:

- `background.ts` — service worker; listens for `rmp:searchProfessors` messages and proxies to the RMP API
- `content.ts` — content script targeting `*://ssbstureg.gmu.edu/StudentRegistrationSsb/*`; observes `#table1` DOM mutations and enhances registration table columns with RMP data
- `popup/` — SolidJS popup UI (`index.html` + `main.tsx` entry)

Utilities in `src/utils/`:
- `rmp.ts` — RMP GraphQL API client. Zod-validated responses, cursor-based pagination, normalized interfaces
- `enhance-columns.ts` — per-column DOM enhancers for the registration table; caches professor lookups in memory
- `carousel.ts` — vertical carousel helper (currently unused)

Root reference files:
- `registration.html` — saved GMU registration page for offline DOM inspection
- `row.html` — saved single table row for reference
- `rpm-spec.md` — RMP GraphQL API reference docs (not source code)

## Key Conventions

- `tsconfig.json` uses `"jsx": "preserve"` + `"jsxImportSource": "solid-js"` — SolidJS JSX, **not React**
- Path alias `@/` maps to `src/` (WXT convention with `srcDir: "src"`)
- All RMP API responses validated with Zod schemas before use
- RMP auth token (`dGVzdDp0ZXN0`) is a public hardcoded token, not a secret
- GMU's RMP school legacy ID is `352` (exported as `GMU_SCHOOL_LEGACY_ID` in `rmp.ts`)
- `wxt.config.ts` grants `host_permissions` for `https://www.ratemyprofessors.com/*`

## Gotchas

- `.wxt/` is gitignored and auto-generated — never edit manually; `bun install` or `wxt prepare` regenerates it
- WXT file-based routing: adding a file to `src/entrypoints/` automatically registers it in the manifest
- `.output/` is the build output, also gitignored
- Content script communicates with background via `browser.runtime.sendMessage` (message type `rmp:searchProfessors`)
- Professor name matching is fuzzy: normalizes both search and RMP names, checks all search words appear in RMP name
